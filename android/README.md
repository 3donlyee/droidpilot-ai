# DroidPilot AI — Android app

> Android (Kotlin) source for the DroidPilot AI on-device agent.
> Target device: **OPPO Reno5 (CPH2159), Android 13, ARM64, ColorOS, no root.**

This module implements the on-device half of the DroidPilot AI architecture:

```
Cloudflare Worker ──HTTPS/WSS──▶ DroidPilotForegroundService
                                      │
                                      ├── WorkerClient (OkHttp + WebSocket)
                                      ├── ToolExecutor ── ToolRegistry
                                      │     ├── AccessibilityTools   (get_screen_nodes, tap_element)
                                      │     ├── GestureTools         (swipe_up, swipe_down)
                                      │     ├── AppTools             (open_app, get_device_info)
                                      │     ├── ShellTools           (run_shell, policy-gated)
                                      │     ├── ScreenshotTools      (take_screenshot, MVP stub)
                                      │     └── TypeTextTool         (type_text)
                                      ├── CommandValidator  (SAFE / REQUIRES_CONFIRMATION / BLOCKED)
                                      ├── AdbBridge (Phase 7 stub)
                                      └── DroidPilotAccessibilityService (Android Accessibility)
```

## Build

### Prerequisites

- **JDK 17** (Android Gradle Plugin 8.5 requires JDK 17)
- **Android SDK** with `platform-34` and `build-tools;34.0.0`
- **Gradle 8.5+** (or use the bundled wrapper after running `bootstrap.sh` once)
- (Recommended) **Android Studio Koala 2024.1.1+** for the simplest flow

### First-time setup (wrapper jar)

The Gradle wrapper jar is intentionally **not** committed (it can't be downloaded in the sandbox). Generate it once with one of:

```bash
# Option A — if you have system Gradle installed
cd android
./bootstrap.sh                # runs:  gradle wrapper --gradle-version 8.9

# Option B — manual
cd android
gradle wrapper --gradle-version 8.9 --distribution-type bin

# Option C — just open the folder in Android Studio; it will offer to
#           generate the wrapper automatically on first sync.
```

### Build the APK

```bash
cd android
./gradlew assembleDebug
# → APK at:  app/build/outputs/apk/debug/app-debug.apk
```

Install on the device:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Or build a release APK (keystore required — see Android docs):

```bash
./gradlew assembleRelease
```

## First-run setup (on-device)

1. **Launch** *DroidPilot AI* from your app drawer.
2. **Tap "Enable Accessibility"** → you'll be sent to Android's Accessibility settings.
   Find *DroidPilot AI* in the list → toggle it ON → accept the consent dialog.
3. **Back in the app**, edit the **Worker URL** field to point at your deployed
   Cloudflare Worker (default placeholder: `https://droidpilot-ai.YOUR-SUBDOMAIN.workers.dev`).
4. **Tap "Pair"** → the app POSTs to `/api/device/register` and shows a
   6-digit **pairing code** + your **device_id**.
5. Open the **Web UI** → enter device_id + pairing code → confirm.
6. Once paired, tap **"Start Service"** → the Foreground Service opens the
   WSS command channel. The status indicator will switch to *Connected*
   and the persistent notification reads "DroidPilot AI is connected".

## Communication protocol

### Command (Worker → Device)

```json
{ "type": "command", "id": "cmd_001", "tool": "swipe_up", "arguments": {} }
```

### Result (Device → Worker)

```json
{ "type": "result", "id": "cmd_001", "success": true, "data": { ... } }
```

or on failure:

```json
{ "type": "result", "id": "cmd_001", "success": false,
  "error": { "code": "ELEMENT_NOT_FOUND", "message": "..." } }
```

### `get_screen_nodes` output format

```json
{
  "package": "com.example",
  "elements": [
    {
      "id": "node_a1b2c3d4",
      "text": "Like",
      "description": "Like",
      "clickable": true,
      "enabled": true,
      "bounds": { "left": 400, "top": 1000, "right": 600, "bottom": 1100 }
    }
  ],
  "node_count": 1,
  "hash": "<sha256-of-canonical-tree>"
}
```

The `id` is a stable SHA-1 hash of `bounds|text|description|className`
(truncated to 8 hex chars, prefixed with `node_`). The same logical element
will produce the same id across snapshots, allowing the Worker to dedup trees.

## Tools available to the AI model

| Tool | Description |
|------|-------------|
| `get_device_info` | Model, OS, screen size, battery |
| `get_current_package` | Foreground app package name |
| `get_screen_nodes` | Accessibility tree as compact JSON |
| `open_app(package_name)` | Launch an app |
| `swipe_up` / `swipe_down` | Vertical gestures |
| `tap_element(element_id \| x,y)` | Tap a node by stable id or coordinates |
| `type_text(text)` | Set text on focused editable node |
| `take_screenshot` | MVP stub — returns `SCREENSHOT_REQUIRES_PERMISSION` (Phase 2 will add MediaProjection flow) |
| `run_shell(command)` | Phase 1: returns `ADB_NOT_AVAILABLE`; Phase 7 will route through AdbBridge |

## Shell command policy (CommandValidator)

| Class | Examples |
|-------|---------|
| SAFE                  | `getprop`, `pm list packages`, `dumpsys`, `input tap`, `input swipe`, `wm size`, `settings get` |
| REQUIRES_CONFIRMATION| `pm clear`, `pm uninstall`, `settings put`, `service call`, `kill` |
| BLOCKED               | `rm`, `rm -rf`, `reboot`, `shutdown`, `factory reset`, `dd if=`, `mkfs`, `mount -o remount` |

Unknown commands default to **REQUIRES_CONFIRMATION** (never auto-allowed).

## Permissions used

| Permission | Why |
|------------|-----|
| `INTERNET` | Talk to the Cloudflare Worker |
| `ACCESS_NETWORK_STATE` | Detect connectivity for reconnect backoff |
| `BIND_ACCESSIBILITY_SERVICE` | Read tree + dispatch gestures |
| `FOREGROUND_SERVICE` | Run a persistent command channel |
| `FOREGROUND_SERVICE_SPECIAL_USE` | Android 14+ requires a type for FGS; our use case doesn't fit other buckets |
| `POST_NOTIFICATIONS` | Android 13+ — show the persistent notification |
| `RECEIVE_BOOT_COMPLETED` | (Future) auto-start on boot |
| `WAKE_LOCK` | Keep CPU alive during long-running command sequences |
| `QUERY_ALL_PACKAGES` | `open_app` needs to resolve launch intents across packages |

`usesCleartextTraffic="false"` — HTTPS / WSS only.

## Known limitations (Phase 1 MVP)

- **Screenshot tool** returns `SCREENSHOT_REQUIRES_PERMISSION` until Phase 2
  adds the MediaProjection consent Activity.
- **Shell tool** returns `ADB_NOT_AVAILABLE` until Phase 7 enables the
  AdbBridge via Wireless Debugging. SAFE commands cannot actually run.
- **`device_secret`** is stored in plain SharedPreferences for MVP reliability
  across OEM Keystore quirks. Phase 2 migrates to `EncryptedSharedPreferences`.
- **`type_text`** only works on fields that expose a focused, editable
  AccessibilityNode. WebView / Canvas / SurfaceView-rendered inputs are not
  reachable through this path.
- **No horizontal swipes / long-press / pinch** in MVP (Phase 2 will add them).
- **Accessibility tree node recycling** is best-effort. The framework will
  eventually recycle nodes even if we forget, but excessive unrecycled nodes
  may cause logcat warnings under heavy load.

## Security checklist

- ✅ No secrets / API keys / tokens in any source file
- ✅ Worker URL read at runtime from UI (default placeholder only)
- ✅ `device_secret` is opaque random data from the Worker — no embedded keys
- ✅ HTTPS / WSS only (`usesCleartextTraffic="false"`)
- ✅ Shell commands classified before execution; BLOCKED never reaches the shell
- ✅ ADB bridge is inert in MVP (`isAvailable() == false`)
- ✅ AccessibilityService observes ALL apps but only acts on Worker commands
- ✅ User-visible persistent notification whenever the service is active

## Troubleshooting

**"AccessibilityService not running"**
→ Re-check the Accessibility toggle in *Settings → Accessibility → DroidPilot AI*.
   Some OEMs (notably ColorOS / MIUI) silently kill background accessibility
   services — add DroidPilot AI to the battery optimisation allowlist.

**WebSocket disconnects every few minutes**
→ Enable the WAKE_LOCK path in `DroidPilotForegroundService` (already declared
   in the manifest). Some OEMs also require disabling "battery optimisation"
   for the app.

**`gradlew` doesn't run / `gradle-wrapper.jar` missing**
→ Run `./bootstrap.sh` once (or open in Android Studio).
